A modern static portfolio starter for Ryuf Alzahrani, third-year Data Science student at Umm Al-Qura University.

## Files
- index.html — portfolio content
- styles.css — responsive visual design
- script.js — mobile navigation and project case-study modals

## Colors
All colors live in the `:root` block at the top of `styles.css` as design tokens.
Change a token there and it updates everywhere on the site.
